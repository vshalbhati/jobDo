Automated applying is against LinkedIn's User Agreement and accounts do get restricted for it. Keep the daily cap low, keep the delays long, and read the activity log before you trust a run.

1. Your jobDo account

Your resume and every setting live on your jobDo account and are edited on the jobDo website. This browser downloads them before each run, and checks for changes every 30 minutes.

Server addresses

Only change these if you run your own jobDo server.

2. What the next run will use

This browser's copy of your account, as last downloaded. To change any of it, use the website.

3. Unrecognised career sites

To fill application forms on career sites it does not recognise, the extension needs Chrome's permission, which only this page or the popup can ask for. Whether it also presses Submit there is set on the website.

4. History on this computer

Jobs listed here are never applied to twice. Every application is also saved to your account as it happens.
